# need >=3.11). Developed and tested on 3.14. On Streamlit Community Cloud pick
# the Python version under Advanced settings when you CREATE the app (it cannot
# be changed afterwards) -- 3.14 matches this stack exactly and every compiled
# dependency ships a cp314 wheel. The 3.9 default cannot install streamlit>=1.62
# at all, and the build dies during pip install before the app ever starts.
#
# Floors are the versions this project was developed and tested against. The
# dashboard uses recent Streamlit APIs (st.navigation, tab.open, st.context.theme,
# st.container(horizontal=...), width="stretch"), so an older resolve would import
# fine and then crash at render time -- better to fail at install.

# pyproject.toml regardless of which entrypoint file triggered the build.
